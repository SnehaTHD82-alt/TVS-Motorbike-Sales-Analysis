# TVS Motorbike Sales Trends Analysis

### Data Analysis using Power BI

This project is based on real sales data from a TVS showroom in Purulia. The main goal was to understand which bikes were selling well, what customers were buying, and where the showroom could improve its sales and inventory.

I worked with the sales data in Python to clean and organize it before creating the Power BI dashboard. The dashboard shows sales trends, bike performance, customer preferences, pricing, and other important business information.

I also worked on sales forecasting to get an idea of future demand and help with better inventory planning. Based on the analysis, I suggested ways to improve sales, manage stock, understand customer needs, and increase customer satisfaction and overall revenue.
